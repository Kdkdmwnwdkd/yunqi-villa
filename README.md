# 云栖山庄 · 安卓观景原型

Godot 4.7.2 引擎原生导出的安卓应用。当前阶段只做**山体与植被**，建筑与玩法后续逐步加入。

## 下载

到 [Releases](../../releases) 页面下载最新一版的 `yunqi-villa.apk`。

- 大小：约 38 MB
- 系统：Android 7.0 及以上
- 架构：arm64-v8a（近五年安卓机型）

## 安装

1. 下载 `.apk` 文件
2. 点击安装，系统提示「禁止安装未知应用」时，进入设置打开对应浏览器的安装权限
3. 返回继续安装

## 操作

| 操作 | 效果 |
| --- | --- |
| 按住画面拖动 | 转动视角 |
| 左下摇杆 | 行走，推到底是奔跑 |
| 右下按钮 | 切换自动巡游 / 自由行走 |

## 技术说明

地形由程序化生成，不依赖高程数据。核心在 `scripts/world_data.gd`：

- 高度由「到折线山脊的距离」决定，而非固定半径，避免出现圆形台地
- `shoulder_mask` 控制山肩段变宽变缓，形成自然台地
- 崖壁宽度与落差随位置噪声变化，避免一圈等高的"蛋糕边"
- 地表色图烘焙成 512² 贴图，配合着色器做三平面高频采样与法线扰动
